Frame Multiplier — Request setup

Setup is free. You pay only if you release the frames.

Send us your Figma file and we set up the masters and run the rollout for you. You see every size as a low-res JPEG preview before you decide anything.

How it works

  1. Share the file. In Figma, click Share, set the link to Anyone with the link · can view, and paste it below. View access is enough: we work on our own copy, so nobody is added to your team and your file is not edited.
  2. We check the artwork. If it doesn't suit a rollout we reply and say why, and that is the end of it.
  3. We send previews. You get a view-only link to our copy, with every size filled by a low-res JPEG of its layout.
  4. You release the frames. Releasing costs $1 a frame, with a $99 minimum per rollout. On payment we replace the JPEGs with the working frames and hand the file over.

What to have ready

  • Your finished master layouts on one page of the file.
  • The list of sizes you need, in the file or in the note below.
  • The names of the fonts used. If one is not a Google or Adobe font, say so and we will ask how to get it.
